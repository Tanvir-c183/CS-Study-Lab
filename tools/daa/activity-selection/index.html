🛣️ Greedy Valid

Dijkstra's Shortest Path

Computes single-source shortest paths on non-negatively weighted directed or undirected graphs using greedy tentative distance extraction.

Input: Weighted Graph $G(V,E)$, Source $S$

Time Complexity: $O((|V| + |E|) \log |V|)$

🌳 Greedy Valid

Prim's Minimum Spanning Tree

Grows a continuous minimum spanning tree from an initial root vertex by repeatedly selecting the minimum-weight cut-crossing edge.

Input: Undirected Weighted Graph $G(V,E)$

Time Complexity: $O(|E| \log |V|)$

🔗 Greedy Valid

Kruskal's Minimum Spanning Tree

Constructs an MST by processing globally sorted edges and preventing cycles using Disjoint Set Union (DSU) with Path Compression.

Input: Undirected Weighted Graph $G(V,E)$

Time Complexity: $O(|E| \log |E|)$

📦 Greedy Valid

Huffman Prefix Coding

Generates optimal, prefix-free variable-length binary encoding trees based on character frequency min-heap merges.

Input: Character Frequencies $\{f(c)\}$

Time Complexity: $O(|C| \log |C|)$

🎒 Fractional Only

Knapsack Optimization

Solves continuous Fractional Knapsack using greedy profit-density ratios ($p_i / w_i$) and compares against 0/1 Knapsack DP constraints.

Input: Item Profits, Weights, Capacity $W$

Time Complexity: $O(n \log n)$

🗓️ Greedy Optimal

Activity Selection

Selects the maximum number of mutually compatible activities by repeatedly choosing the activity with the earliest finishing time.

Input: Activities with start time sᵢ and finish time fᵢ

Greedy Rule: Choose the compatible activity with minimum finish time

Time Complexity: O(n log n) unsorted; O(n) if already sorted by finish time

⚠️ Theoretical Contrast:

Greedy selection by profit/weight ratio $p_i / w_i$ is guaranteed optimal for Fractional Knapsack. However, for 0/1 Knapsack, greedy heuristics can lead to suboptimal capacity usage. Dynamic Programming ($O(n W)$) is required for 0/1 optimality.

Optimal Substructure & Greedy Choice

A problem exhibits optimal substructure if an optimal solution to the problem contains optimal solutions to subproblems. The greedy choice property guarantees that a locally optimal choice leads to a globally optimal solution without backtracking.

Cut Property in Spanning Trees

For any cut $(S, V \setminus S)$ of a graph $G$, if an edge $e$ crossing the cut has strictly smaller weight than any other crossing edge, then $e$ must belong to every Minimum Spanning Tree of $G$.
