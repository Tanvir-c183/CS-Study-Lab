6 CRC Theory, Types & Exam Rules

CRC-8

Generator: x⁸ + x² + x + 1, represented by 0x07 after omitting the leading x⁸ coefficient.

CRC-16-CCITT

Generator: x¹⁶ + x¹² + x⁵ + 1, represented by 0x1021.

CRC-16-IBM

Generator: x¹⁶ + x¹⁵ + x² + 1, represented by 0x8005.

CRC-32 IEEE Polynomial

Generator polynomial: 0x04C11DB7, with the leading x³² coefficient understood. This simulator uses direct binary polynomial division for exam work.

CRC-12

Generator: x¹² + x¹¹ + x³ + x² + x + 1. Useful when practicing different generator degrees and remainder lengths.

Important exam distinction: Hamming uses physical bit positions numbered from the right, but CRC long division is performed on the displayed binary stream in the normal left-to-right order. Do not reverse the CRC dataword or remainder merely because Hamming uses RTL position numbering.
