Class Notes & Exam Rules

Classful addressing

Historically, A/B/C used fixed default network boundaries: A=/8, B=/16, C=/24. D and E are not ordinary host classes.

Classless / CIDR

The prefix explicitly states the network length. Example: 172.16.0.0/20. The old class boundary does not determine the network size.

Borrowed bits

When subnetting a classful network, borrowed bits come from the original host portion. New prefix = default prefix + borrowed bits.

Need 256 computers?

For ordinary LAN addressing, 256 usable hosts need at least 258 addresses, so the smallest power-of-two block is 512 addresses = /23, giving 510 usable hosts.

Important /24 fact

A /24 has 256 total addresses but normally only 254 usable host addresses. Borrowing 5 bits from a /24 creates /29, not a 256-host subnet; /29 has only 6 usable hosts per subnet.

Network calculation

Network = IP AND subnet mask. Broadcast = network + block size − 1. Host range lies between them for ordinary subnets.

VLSM

Different subnets can use different prefix lengths. Allocate the largest host requirement first to avoid fragmentation.

Wildcard mask

Wildcard = 255.255.255.255 − subnet mask. It is useful in ACL and routing contexts.

Exam workflow

Write prefix → host bits → block size → boundary → network → first host → last host → broadcast → verify capacity.

Key correction to remember: “Borrowing 5 bits” is a subnetting operation, not a way to obtain 256 hosts. From a /24, borrowing 5 bits gives /29. If you need 256 usable hosts, you need /23 (512 total addresses, 510 usable), which requires a larger address block than a single /24.
