7 Code Geometry, SEC-DED & Multi-Bit Limitations

Understand minimum distance properties, syndrome aliasing during multi-bit noise, and Extended Hamming codes.

Limitations & Theory

⚠️ CRITICAL LIMITATION: Standard Hamming Code Multi-Bit Aliasing

Standard Hamming codes achieve a minimum Hamming distance of $d_{\min} = 3$. This mathematically guarantees single-bit error correction ($t_{\text{correct}} = 1$) or double-bit error detection ($t_{\text{detect}} = 2$), but not both simultaneously.

If a transmission suffers two simultaneous bit errors ($w_H(e) = 2$), the modulo-2 sum of two parity matrix columns yields a third valid column within the matrix. The decoder suffers syndrome aliasing: it mistakes the double error for a single error at an uncorrupted bit position, flips that bit, and increases the total corruption to 3 errors!

Standard Hamming Code
$d_{\min} = 3$
  • Parity Bits: $r$ occupying power-of-two positions.
  • Syndrome State ($S$): Directly identifies 1-bit error location ($1 \dots n$).
  • Vulnerability: Multi-bit errors produce aliased syndromes, causing silent miscorrection.
Extended Hamming (SEC-DED)
$d_{\min} = 4$
  • Adds a global parity bit $P_0$ covering all $n$ bits at Position 0.
  • If $S \ne 0$ and $P_0$ fails: Confirmed single-bit error (Corrected).
  • If $S \ne 0$ and $P_0$ passes: Confirmed double-bit error (Halt correction to avoid silent corruption).
  1. Data Word Ingestion: Accept binary data string (e.g. `1011`). Internal indices map rightmost bit to $D_1$.
  2. Parity Bound Calculation: Solve $2^r \ge m + r + 1$ to determine required parity bits ($r$).
  3. Power-of-Two Interleaving: Reserve positions $1, 2, 4, 8 \dots$ for parity bits. Insert data bits into non-power-of-two coordinates ($3, 5, 6, 7 \dots$).
  4. Parity Evaluation: For each $P_{2^j}$, evaluate modulo-2 XOR sum across covered positions where bit weight $2^j$ is set.
  5. Codeword Assembly: Serialize parity and data bits into the final block.
  6. Channel Transmission: Codeword travels across noisy physical medium.
  7. Syndrome Recalculation: Recheck parity equations over received vector $R$ to produce syndrome bits $S_1, S_2, S_4 \dots$.
  8. Error Localization & Inversion: Integer value of binary syndrome $S$ indicates the exact error position ($R(S) \oplus 1$). If $S=0$, vector is valid.
