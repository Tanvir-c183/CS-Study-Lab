Golden Rules & Calculation Shortcuts

Understanding network segmentation requires recognizing how devices process frames (Layer 2) and packets (Layer 3). Use these reference cards to solve any complex hierarchical network topology in seconds.

Layer 1 Physical 🔌

Hub / Multiport Repeater

  • Collision Domain: Shares 1 single domain across ALL connected ports (even when nested/cascaded).
  • Broadcast Domain: Forwards broadcasts to all ports. Does NOT isolate subnets.
  • Rule: Cascading Hubs together still results in 1 single shared collision domain.
Layer 2 Data Link 🔀

Switch / Bridge

  • Collision Domain: Every active port creates 1 isolated collision domain.
  • Broadcast Domain: Forwards broadcasts. All ports belong to 1 broadcast domain (without VLANs).
  • Rule: Switches isolate collisions, but pass broadcasts.
Layer 3 Network 🌐

Router

  • Collision Domain: Every active router interface forms 1 collision domain.
  • Broadcast Domain: Every active interface forms a separate broadcast domain (subnet).
  • Rule: Routers block broadcast frames completely.

⚠️ The Nested Hub Rule (Layer 1 Cascading)

When a Hub (H1) is connected to another Hub (H2) under a Switch port, they do NOT create separate collision domains. Because hubs simply repeat electrical signals, the entire tree of interconnected hubs and their connected PCs form 1 SINGLE shared Collision Domain off that switch port!
