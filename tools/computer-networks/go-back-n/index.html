Sender Finite State Machine (FSM)

Event 1: Request from Upper Layer

If S_next < S_base + WT: Build packet S_next, send frame, start timer if S_base == S_next, S_next++. Else: Buffer / Block.

Event 2: Cumulative ACK Received (ACKy)

Slide base forward: S_base = y + 1. If S_base == S_next: Stop timer. Else: Restart timer for oldest unACKed.

Event 3: Timer Expiration (Oldest Frame)

Go-Back Cascade: Restart timer; retransmit all frames from S_base through S_next-1.

Receiver Finite State Machine (FSM)

Event 1: Correct In-Order Frame Arrives (Seq == R_next)

Accept payload, pass to Upper Layer. Advance expectation R_next = (R_next + 1) mod2m. Send cumulative ACK.

Event 2: Out-of-Order or Corrupted Frame Arrives

Discard frame completely. Resend cumulative ACK for the last correctly received in-order sequence number.

Crucial Constraint: WR = 1

No out-of-order storage buffers exist on the receiver, enforcing the cascade retransmission property of Go-Back-N.

The Sequence Space Invariant: Why WT ≤ 2m - 1? If WT = 2m, suppose frames 0, 1, …, 2m-1 are sent and accepted by the receiver, but all ACKs are lost. The receiver advances expectation to 0. When the sender times out and retransmits frame 0 (old generation), the receiver cannot distinguish whether it is a duplicate of the old frame or the brand-new frame 0 of the next cycle. Restricting WT ≤ 2m - 1 guarantees that the sender window and the receiver expected window never overlap ambiguously.

Go-Back-N ARQ Formula Sheet

Quick reference for examination, revision, and simulation interpretation.

Basic Timing

Tt = L / B
Tp = d / v
a = Tp / Tt
RTT ≈ 2Tp

GBN Efficiency

η = min(1, W / (1 + 2a))
Wmin = ceil(1 + 2a)
Throughput = η × B
WT = W,   WR = 1

Sequence Numbers

Sequence space = 2m
Wmax = 2m − 1
m ≥ ceil(log2(W + 1))
W ≤ 2m − 1

Retransmission Logic

Timeout: retransmit every outstanding frame from the oldest unacknowledged frame. Every retransmission is a new Host-A transmission and gets a new TX #; retransmissions remain pipelined with the same small inter-frame spacing as normal sending.
Cumulative ACK: advances the sender base past all consecutively acknowledged frames.
Out-of-order frame: receiver discards it because WR = 1.

Useful Rearrangements

L = Tt × B
B = L / Tt
Tp = a × Tt
W ≥ (1 + 2a)η
η = Throughput / B
v = d / Tp
Exam unit reminder: keep units consistent. Convert kbps to bps, Mbps to bps, km to m, and ms to s before substitution. For Go-Back-N, remember the sequence-space constraint W ≤ 2m − 1.
