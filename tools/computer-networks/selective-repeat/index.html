Module 1: Selective Repeat ARQ Operational Engine

Unlike Go-Back-N, Selective Repeat allows the receiver to accept and buffer out-of-order frames within its window (WR = N). Every frame runs an independent timer. Upon timeout, only the missing frame is retransmitted. When the missing frame arrives, an atomic contiguous buffer drain delivers all in-sequence buffered frames to the application layer.

Module 3: Formal Protocol Theory, FSM Architectures & Proofs

Comprehensive reference for the mathematical foundations of Selective Repeat ARQ, finite state machine transition matrices, sequence space bounds, and comparative trade-off analyses.

Sender Finite State Machine (FSM)

1. WINDOW_AVAILABLE State

Guard: Snext < Sbase + WT. Encapsulates frame with sequence Seq = Snext mod M, transmits frame, starts frame-specific timer Timer(Snext), and increments Snext.

2. WAITING_FOR_ACK State

Monitors incoming selective ACKs. Upon receiving ACKk, halts Timer(k) and marks frame k acknowledged. If k == Sbase, advances Sbase to the lowest unacknowledged index.

3. SELECTIVE_RETRANSMIT State

Trigger: Expiration of Timer(k). Transmits only frame Fk. Restarts Timer(k). Does not retransmit succeeding frames in the pipeline.

Receiver Finite State Machine (FSM)

1. IN_ORDER_RECEIVE State

Arrival of Fk where k == Rbase. Delivers frame to application, emits ACKk, scans reassembly buffer for contiguous successors, delivers buffered stream, and advances Rbase.

2. OUT_OF_ORDER_BUFFER State

Arrival of Fk where Rbase < k < Rbase + WR. Stores payload in reassembly slot k, emits selective ACKk, and holds Rbase stationary.

3. DUPLICATE_FRAME Handling

Arrival of Fk where k < Rbase (due to lost ACK). Discards duplicate payload, re-emits ACKk to enable sender window advancement.

📐 Sequence Space Constraint Proof: WT + WR ≤ M

A fundamental design constraint of sliding window protocols is preventing sequence number ambiguity between frames of the current window cycle and retransmitted frames from the previous cycle.

Mathematical Formulation:

Let sequence numbers be evaluated modulo M = 2ᵐ. For symmetric sender and receiver windows (WT = WR = W):

WT + WR ≤ M  ⟹  2W ≤ M  ⟹  W ≤ M / 2 = 2ᵐ⁻¹

Failure Proof (Why W > M/2 Fails): Suppose m = 3 (M = 8) and we illegally set W = 5. Sender transmits frames 0, 1, 2, 3, 4. Receiver accepts all 5 frames, generates ACKs, and advances its acceptance window to [5, 6, 7, 0, 1]. If all 5 ACKs are lost in transit, the sender times out and retransmits frame 0. When sequence number 0 arrives, the receiver cannot determine whether sequence 0 is an old duplicate or the new frame 0 in its advanced window!
