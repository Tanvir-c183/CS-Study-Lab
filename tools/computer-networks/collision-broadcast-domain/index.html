④ Exam Theory — Domain Rules
COLLISION DOMAIN

What is it?

A collision domain is a portion of an Ethernet network in which simultaneous transmissions can contend for the same shared medium and potentially collide.

Hub: all attached stations share one collision domain.
Switch: each active switch port is a separate collision domain.
Correct full-duplex Ethernet: collisions do not occur, so CSMA/CD is not used on that link.
BROADCAST DOMAIN

What is it?

A broadcast domain is the set of Layer-2 interfaces that receive a Layer-2 broadcast unless a Layer-3 boundary or another configured mechanism stops it.

Hub: one broadcast domain for the connected segment.
Switch: one broadcast domain per VLAN.
Router: separates broadcast domains at routed interfaces.
