# CS Study Lab 🧪

**Interactive computer science study tools, question solvers, simulators and visualizers — built for learning by doing.**

🌐 **Live Study Lab:** https://tanvir-c183.github.io/CS-Study-Lab/

📦 **GitHub Repository:** https://github.com/Tanvir-c183/CS-Study-Lab

## What is CS Study Lab?

CS Study Lab is a growing collection of browser-based learning tools for computer science and engineering students.

Instead of only reading theory, you can **enter values, run algorithms, visualize results, explore network behavior and practice concepts interactively**.

The collection is designed to grow as new subjects and study topics are covered.

## 🧰 Current Study Tools

### Design & Analysis of Algorithms (DAA)

- Dynamic Programming Solver
- Greedy Algorithm Solver
- Activity Selection Solver
- Graham Scan Visualizer

### Computer Networks

- Go-Back-N ARQ Simulator
- Selective Repeat ARQ
- Stop-and-Wait ARQ
- CIDR / VLSM Workbench
- Hamming Code Simulator
- CRC Simulator
- Ethernet / Wi-Fi Visualizer
- Collision & Broadcast Domain Explorer
- Network Domain Hierarchy Explorer

## 🎯 Who is it for?

- CSE / CS students
- Engineering students
- Students preparing for practicals and exams
- Learners who want to understand algorithms visually
- Anyone looking for interactive browser-based CS practice tools

## 🚀 Why this project?

CS concepts can be easier to understand when you can **see the algorithm execute instead of only reading its steps**.

CS Study Lab brings multiple small educational tools into one searchable, organized study portal.
